# Reward Searcher

App Android com Material Design 3 Expressive para automatizar pesquisas no Microsoft Rewards.

## Funcionalidades

- Defina a quantidade de pesquisas (1-100)
- Abre pesquisas no Bing ou Chrome automaticamente
- Overlay flutuante com progresso em tempo real
- Pausar / Continuar / Cancelar durante a execução
- Tela de configurações (intervalo, navegador, tema)
- Material You com cores dinâmicas

## Build

O APK é compilado automaticamente via GitHub Actions em cada push na branch `main`.

## Requisitos

- Android 8.0+ (API 26)
- Permissão de sobreposição de tela
- Bing ou Chrome instalado
